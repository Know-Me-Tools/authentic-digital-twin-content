# Portable development and evidence teams

## Why

The content skill needs durable specialist ownership for authorized evidence,
provenance, Rust ingestion and MCP interoperability, retrieval, and storage. Its
current shell hooks prevent native Windows use and its globally installed skills
do not travel with a standalone copy.

## What Changes

- Define a twelve-role team with disjoint ownership, specialist handoffs, and
  independent review. Export six native formats and Zed instruction/skill routing.
- Research protocol/storage/client contracts and vendor the required companion
  skills with license and provenance records inside a portable skill bundle.
- Replace shell hooks with TypeScript 7 sources and Node.js .mjs output.
- Install project discovery and provide a portable installer for downstream users.

## Capabilities

### New Capabilities
- `portable-agent-teams`: team definitions, bundled skills, native proposals,
  cross-platform hooks and installation verification.

## Impact

Agent configuration, maintenance docs, development helpers, and skill packaging.
No Rust service, private evidence collection, remote graph writes, external
messages, model subscriptions, or live agent activation is part of this change.
